# 🌾 DalaScan AI

**Предварительная диагностика заболеваний пшеницы по фотографии.**
Проект для AgriTech AI Hackathon: трек 3 «Компьютерное зрение в агрономии», задача 3.1.
Помогает фермеру и агроному начать обследование растений и сохранить результат в PDF.

## 1. Как запустить

Установите **Python 3.11 (64-bit)**, скачайте [репозиторий](https://github.com/okimf6/DalaAI) и откройте PowerShell в папке с `app.py`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте **http://localhost:8501**. Активация виртуального окружения не требуется. Для остановки нажмите Ctrl+C.

**Настоящая диагностика:** нужны обученные веса `model/wheat_model.pth` и модель проверки снимков. Веса не входят в Git. Если файл `wheat_model.pth` уже предоставлен с проектом, поместите его в папку `model`, скачайте проверку снимков и запустите приложение:

```powershell
.\.venv\Scripts\python.exe scripts/download_guard.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`download_guard.py` однократно скачивает около 605 МБ весов CLIP. После подготовки анализ работает локально, без внешних API и ключей.

**Если обученных весов нет**, их можно получить на реальных данных следующими командами перед запуском приложения. Требуются интернет для первичной загрузки и время для обучения:

```powershell
.\.venv\Scripts\python.exe scripts/prepare_dataset.py
.\.venv\Scripts\python.exe scripts/train_model.py --data dataset --epochs 15 --batch-size 16 --lr 0.0003 --balanced --selection macro_f1 --output model/wheat_model.pth
.\.venv\Scripts\python.exe scripts/download_guard.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Подготовка скачивает архив Kaggle около 1 ГБ; папки `dataset` и `dataset_raw` должны быть пустыми или отсутствовать. Повторное обучение создаёт новую модель: её метрики могут отличаться от приведённых ниже. Подробности улучшения текущих весов сохранены в [отчёте сравнения](model/rust_improvement.json).

**Сценарий проверки жюри:** отключите «Демонстрационный режим», загрузите фотографию листа пшеницы (например, из `dataset/test` после подготовки данных), нажмите «Провести диагностику». Посмотрите состояние, вероятности, время и рекомендации; переключите Русский / Қазақша и скачайте PDF. Если снимок не прошёл проверку CLIP, приложение покажет отказ и предложит переснять лист.

Без весов доступен **демонстрационный режим** — только проверка интерфейса, не настоящее распознавание. Тесты запускаются командой:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## 3. Что использовалось

| Компонент | Назначение |
|---|---|
| Python 3.11 и Streamlit | Приложение и интерфейс |
| Pillow и NumPy | Подготовка и проверка качества изображений |
| PyTorch и torchvision | Обучение и локальное распознавание |
| MobileNetV3 Small, предобученная на ImageNet | Классификация состояния пшеницы после дообучения |
| CLIP ViT-B/32 и Transformers | Экспериментальная проверка «похож ли снимок на пшеницу» |
| ReportLab | PDF-отчёты |
| pytest | Автоматические тесты |

Модель различает **здоровую пшеницу, бурую ржавчину, жёлтую ржавчину и септориоз**. CLIP может ошибаться на похожих злаках; это вспомогательная проверка, а не подтверждение вида растения.

Данные: [Wheat Disease Dataset — Small на Kaggle](https://www.kaggle.com/datasets/yasserhessein/wheat-disease-dataset-small). Для четырёх классов использованы **838 реальных снимков**: 583 train, 128 validation, 127 test. Точные дубликаты удаляются, похожие кадры группируются перед разбиением. Искусственно созданные фотографии в датасет не добавлялись; отражения, повороты, crop и изменение яркости/контраста применяются только к train как аугментации.

Авторы, лицензия и история источника данных: [DATASET_LICENSE.md](data/DATASET_LICENSE.md). Первоначальные веса обучались на копии с Zenodo; дообучение выполнено на заново скачанной копии Kaggle с совпадающими изображениями. Сведения о предобученном CLIP: [IMAGE_GUARD.md](model/IMAGE_GUARD.md).

**Результаты текущего классификатора на 127 test-снимках:**

| Метрика | Значение |
|---|---:|
| Accuracy | **84,25%** |
| Macro-F1 | **0,8399** |
| Обнаружение бурой ржавчины (recall) | **78,95% — 15 из 19 снимков** |

Источник: [метрики модели](model/wheat_model.metrics.json). Это внутренняя выборка, ранее использованная для оценки исходной модели; результаты не являются независимой полевой проверкой или метриками всей системы с CLIP и отказами. SHA-256 текущих весов: `33a47252d7ea711b3e2c28dcc1e2400a2502f50a7002b803404217dd91adb0de`.

Приложение показывает время обработки, но полный отклик до 5 секунд с передачей фото при слабом интернете пока не подтверждён. После установки локальный сервер работает без внешнего интернета; автономный запуск непосредственно на телефоне не реализован.


## 4. Будущие перспективы

- Провести пилотные испытания на новых снимках из хозяйств Акмолинской области совместно с агрономами.
- Расширить данные по сортам, сезонам и освещению; повысить качество распознавания болезней и похожих злаков.
- Добавить новые болезни и культуры после сбора размеченных данных и отдельной проверки качества.
- Улучшить работу с телефона и при слабом интернете, уменьшить объём передаваемых фотографий.
- Развить историю обследований по полям и сравнение состояния растений во времени.

Ожидаемая польза — сокращение времени первичного обследования и удобная передача наблюдений агроному. Экономический эффект предстоит измерить в пилоте: сравнить затраты времени и число ошибочных решений с обычным обследованием. Рост урожайности и снижение потерь пока не заявляются как доказанные результаты.
