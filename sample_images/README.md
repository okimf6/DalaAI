# Фотографии для демонстрации

Добавьте свои JPG, PNG или WEBP с разрешением на использование. Нужны крупные планы отдельных листьев здоровой пшеницы и трёх заболеваний. Эти файлы исключены из Git.

Настоящие фотографии и размеченный датасет в поставку не входят. Синтетические картинки в тестах проверяют код, а не качество распознавания.
