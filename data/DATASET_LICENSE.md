# Источник обучающих данных

Использован **Wheat Disease Dataset — Small**, версия v1 (2022).
Авторы: Megan Long, James K. M. Brown, Richard J. Morris, Matthew Hartley.
Организации: John Innes Centre; European Bioinformatics Institute.

Первоисточник и DOI (атрибуция авторов, не адрес загрузки): https://doi.org/10.5281/zenodo.7307816
Текущий источник загрузки: https://www.kaggle.com/datasets/yasserhessein/wheat-disease-dataset-small
Публикация на Kaggle: Yasir Hussein Shakir.
На Kaggle лицензия обозначена как Other (specified in description); CC BY 4.0
указана в метаданных оригинальной публикации авторов. Авторство и DOI сохраняются.
Лицензия: **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
Текст лицензии: https://creativecommons.org/licenses/by/4.0/

Для четырёх классов DalaScan отобраны 838 изображений:
Healthy → healthy; BrownRust → leaf_rust; Septoria → septoria;
YellowRust → yellow_rust. Mildew не используется.

Изменения: исправление EXIF, RGB, уменьшение до 768 px с сохранением пропорций;
удаление точных RGB-дублей; группировка близких кадров по dHash и разбиение
на train/val/test; случайные аугментации только в обучающем преобразовании.
Архив скачивается непосредственно через публичный API Kaggle. URL, дата загрузки
и SHA-256 архива сохраняются в манифесте. SHA-256 фиксирует полученный архив,
но не является подписью издателя.
Манифест с SHA-256, назначением групп и разбиением сохраняется в dataset/manifest.json.

Представленные метрики относятся к внутренней отложенной выборке этого набора.
Метаданных о растениях и полях нет: независимость на уровне растения или поля
не доказана. Группировка dHash уменьшает риск утечки похожих кадров, но не исключает её.
Необходимы самостоятельные испытания на новых полях и проверка агрономом.
Авторы исходных данных не заявляли одобрение этого приложения.

При распространении данных сохраняйте указание авторов, DOI, лицензию и описание изменений.
Сырые изображения не входят в Git и ZIP приложения. Обученные веса созданы в рамках
проекта; информация об источнике обучения поставляется вместе с ними.

## История перехода на Kaggle

До 20.09.2026 данные скачивались с Zenodo. Новый загрузчик получает архив с Kaggle.
Ранее обученные веса не становятся обученными на новой загрузке автоматически:
их исторический источник остаётся Zenodo. Для весов с новой историей обучения
запустите обучение на текущей папке dataset. Резервная копия прежних данных
сохраняется вне поставляемого проекта.

Проверка 20.09.2026: архив Kaggle скачан заново; все 838 выбранных PNG
побайтово совпали с прежними файлами. RGB-хеши и распределение train/val/test
совпали. Рабочая папка dataset заменена данными из новой загрузки.
Подтверждение: data/KAGGLE_DOWNLOAD.json (URL, дата, SHA-256 архива и количества).
Существующие веса оставлены без изменений и не переобучались при смене источника.

## Дообучение после перехода

20.09.2026 исходная модель дополнительно обучена на train из копии Kaggle
с балансировкой классов; выбран checkpoint третьей эпохи по validation Macro-F1.
Текущий wheat_model.pth заменён улучшенной версией, исходные веса сохранены отдельно.
Происхождение исходных весов — предыдущий этап с Zenodo, дообучения — Kaggle.
Метрики и ограничения сравнения: model/rust_improvement.json и README.md.
